# Security Policy

## Reporting a Vulnerability

**DO NOT OPEN A PUBLIC ISSUE** if you think you have found a security issue with RapidQuery.

Instead, navigate to "Security & quality" tab for the repository and use "Report a vulnerability" button.

Be sure to:

- Describe the issue clearly and
- include as much detail as necessary in your report.
- Also a minimal example will help to find the issue faster.

Thank you for helping.
